# Activity 9

This activity focuses on implementing event listeners in JavaScript to modify the behavior of form fields. Specifically, we added event listeners for `focus` and `blur` events on input fields, validated form input, displayed dynamic notifications upon successful registration, and styled the interface accordingly.
