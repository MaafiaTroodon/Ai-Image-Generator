# Activity / Lab / Assignment / Project Title

**[Optional]** This project is an enhanced version of the Magic 8-Ball application. It introduces a Fortune Cookie option alongside the classic Magic 8-Ball functionality. Users can ask a question and either get an answer from the Magic 8-Ball or receive a random fortune. The project demonstrates HTML, CSS, and JavaScript integration, along with DOM manipulation and randomization techniques.
